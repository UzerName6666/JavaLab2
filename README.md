# Задание 1
## Задача 1
### Текст задачи
Время. 

Создайте сущность Время, которое будет описывать текущее время суток в 24-х часовом
формате. Время описывается числом секунд, прошедшим с начала суток. Время может быть
приведено к текстовой форме следующего формата: “ЧЧ:ММ:СС”. Например,если время задано как
12000, то текстовая форма будет “3:20:00”. Если общее время превышает 24 часа, то отображаться
в текстовом виде должно только то время, которое прошло с начала последних суток, например
91800, это не 25:30:00, а 1:30:00.

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:

• 10 секунд

• 10000 секунд

• 100000 секунд

### Алгоритм решения
Был создан класс Time, который хранит в себе 1 число, 3 конструктора (секунды, минуты и секунды, часы минуты и секунды), методы toString, добавления времени и нормализации времени.

Конструкторы: Значению времени присвается a секунд + 60b минут + 3600c часов, после этого значение нормализуется.

Добавление: аналогично как с конструкторами, но прибавляется время вместо присваивания.

Нормализация: Если время отрицательно - то к нему прибавляется 86400 секунд (1 день) пока оно не станет положительным. После этого берётся остаток от деления 86400 секунд 

toString: Время выводится в формате ЧЧ:ММ:СС. 
Для вычисления времени берётся значение времени и постепенно раскладывается на секунды, минуты и часы с  помощью деления и остатка от деления.
Если какое либо число меньше 10, то слева к нему приписывается 0

запросить текстовую форму, которое имеет представление вида “дом с N этажами”, где N это

Создать
и вывести на экран дома с 1, 5, 23 этажами.
### Алгоритм решения
Был создан класс House, который хранит в себе 1 число, конструктор, методы toString.

toString: Если у дома 0 этажей, то выводится "дом без этажей". Если у дома 1 этаж, то выводится "дом с 1 этажом". Если у дома более 1 этажа, то выводится "дом с N этажами"


# Задание 2
### Текст задачи
Сотрудники и отделы.

Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в
котором сотрудник работает, причем у каждого отдела есть название и начальник, который
также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: “Имя
работает в отделе Название, начальник которого Имя”. В случае если сотрудник является
руководителем отдела, то текстовая форма должна быть “Имя начальник отдела Название”.

Необходимо выполнить следующие задачи:
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен
оказаться один и тот же отдел и начальник).
### Алгоритм решения
Было реализовано 2 класса: Worker и Department

В классе Worker хранится департмент и имя сотрудника

В классе Department хранится лидер и название департмента

При создании этих объектов требуется указать только имя.

Для присваивания сотрудника к департменту вызывается метод у сотрудника, который присваивает департмент (Было изменено в другом задании)

Для присваивания начальника департмента у департмента вызывается функция, которая прикрепляет сотрудника к департменту, помечает как начальника и, если он был начальником другого департамента, то открепляет его от лидерства.

Вывод информации о сотруднике:
1) Без департамента - 'c', сотрудник без отдела
2) Дебартамент без начальника - 'c', сотрудник отдела без начальника
3) Начальник отдела - 'c' начальник отдела 'b'
3) Дебартамент с начальником - 'c', сотрудник отдела 'а', начальник которого 'b'

# Задание 5
### Текст задачи
Пистолет стреляет.

• Создайте сущность Пистолет, которая описывается следующим образом:

• Имеет Количество патронов (целое число)

• Может быть создан с указанием начального количества патронов

• Может быть создан без указания начального количества патронов, в этом случае он
изначально заряжен пятью патронами.

• Может Стрелять, что приводит к выводу на экран текста “Бах!” в том случае, если
количество патронов больше нуля, иначе делает “Клац!”. После каждого выстрела (когда
вывелся “Бах!”) количество патронов уменьшается на один.

Создайте пистолет с тремя патронами и выстрелите из него пять раз.
### Алгоритм решения
Был создан класс Gun, в котором хранится число патрон, конструктор и метод выстрела

В конструкторе указывается число выстрелов. Если число пуль меньше 0, то количество устанавливается на 0. Если не указано количества пуль, то устанавливается 5 пуль.

При каждом выстреле пока пуль больше 0, количество пуль уменьшается на 1 и возращается строка "Бах!", иначе возращается "Клац!"
